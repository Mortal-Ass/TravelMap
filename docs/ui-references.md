# UI 参考与本轮改进

- Cairn：https://github.com/thkleinert/cairn —— 旅行空间、地点与地图的功能组织。
- shadcn/ui：https://ui.shadcn.com/blocks —— 表单间距、控件状态与视觉层级。
- Square UI：https://github.com/zerostaticthemes/square-ui —— 列表选中态、柔和边界与留白。

本轮独立编写 CSS，不复制项目品牌和源码，不安装新组件库。采用暖白、松绿色、编辑式标题、抽象山形装饰、清晰焦点与移动端布局。装饰不代表真实地图。保持 Phase 1 功能范围。
